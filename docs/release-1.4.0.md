# 邮件中心 1.4.0

两个界面上的调整，功能没有变化。

## 切换按钮

「站内模板 / 自定义模板」、写邮件里的收件人来源、触发规则的收件人来源，这些切换按钮在 1.3.0 里被做成了白底加一条下划线，看着不像按钮。现在改成：选中的那一项整块用主题色填充、文字变白，没选中的仍是白底。位置和顺序不变，只是能一眼看出当前在哪一栏。

## 预览

模板预览原来固定 320px 高，屏幕再大也只显示那么一小条，稍微长一点的邮件就要在弹窗里上下滑。

现在预览面板几乎占满窗口：高度 92vh、宽度 1120px，邮件本身撑满剩下的高度，一屏能看完一整封常规模板。标题栏右侧新增两个按钮：

- **在新窗口打开**：把这封邮件单独开一个浏览器标签，屏幕再小也能整页看；
- **看纯文本**：切换到这个模板的纯文本版本，方便检查有些邮件客户端只显示文本时的效果。

发送记录详情里「发送出去的样式」也一并放大到 62vh，不再挤在窄条里。

## 升级说明

上传 `plugin-mail-center-1.4.0.jar` 覆盖即可，模板、规则、发信配置和发送记录都会保留。
