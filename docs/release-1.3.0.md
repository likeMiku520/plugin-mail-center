# 邮件中心 1.3.0

这一版主要做两件事：把模板变成一个可以在外面编辑、再整份导回来的文件，以及把几个「看不见」的地方补上。

## 导出一份文件，改完再导回来

「邮件中心」右上角新增「导出模板文件」和「导入模板文件」。

导出的是一份 JSON，里面有三段：

- `builtin`：Halo 自带的通知模板；
- `custom`：在插件里创建的模板，含友链回信那两个；
- `system`：插件自带的模板，目前是发送测试用的那封邮件。

每一条都带着自己的 `title`、`subject`、`htmlBody`、`rawBody` 和可用的变量，另有 `globals` 说明所有模板都能用的站点变量。这份文件可以直接整份交给编辑工具，让它在保留结构的前提下批量改样式。

导入侧刻意做得保守。选好文件后插件先做一次只读核对，页面上列出每一条的结论——会更新、没变化、被跳过、有错误，各自附上原因，确认之后才真正写入。写入规则是：

- 只修改已经存在的同名模板，`name` 对不上就跳过，不新建也不删除；
- 字段留空表示保持原样，未知字段忽略，单条写坏只影响那一条；
- 内容和现状一致的条目不产生写入，所以同一份文件导入两次不会重复改动；
- `builtin` 写完会打上「已自定义」标记，Halo 升级不再覆盖，想恢复用「重置」。

## 站内模板编辑能看到全部变量

编辑面板会把当前通知类型能用的变量全部列出来，每一项标着中文说明和是否必填，点「插入」就写进光标所在位置；下面还有一排通用的站点变量。之前只有一句「例如 commenter、postTitle」的提示，等于让人对着空模板猜变量名。

## 测试邮件可以改

「发信设置」里的发送测试用的就是一封模板，现在它排在站内模板最上面，可以编辑、预览、重置，也会出现在导出的文件里。改完保存，下一次测试就按新的内容发。

## 发送记录能点开

每条记录都可以点开，看到收件人、发送时间、模板、来源、规则名、去重键、耗时和失败原因，以及当时真正发出去的那份邮件。邮件正文是这一版开始随记录保存的，更早的记录只能看到元信息，详情里会说明这一点。

列表上方新增来源筛选，手动发送、自动规则、触发接口、站点通知可以分开查看。

## 触发规则的收件人

新建规则时的收件人分成两步：

- **主要收件人**：事件当事人、被评论文章的作者，或者只发给固定邮箱；
- **额外收件人**：从站内用户、留言过的访客里勾选，也可以直接手填邮箱。

两批地址会去重之后一起发送，同一个邮箱不会收到两封。之前只能手填一串邮箱，站内用户和老访客的地址得自己记。

## 界面

切换分类的按钮改成白底，选中的那个用一条细下划线标记，不再整块铺主题色。卡片去掉阴影改成细边框，提示条、标签、列表都换成中性灰，主题色只留在主按钮和少数需要指路的地方。

「发信设置」里「每分钟限流」的输入框之前是透明的，只看得见数字，现在和其它输入框一样有边框和背景。

## 升级说明

上传 `plugin-mail-center-1.3.0.jar` 覆盖即可，原有的模板、规则、发信配置和发送记录都会保留。

升级后插件会自己创建「测试邮件」这份模板记录，不需要手动做什么。发送记录里的邮件正文从这一版才开始留存，因此升级前的记录没有样式可看。
