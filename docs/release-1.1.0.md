# 邮件中心 1.1.0

这一版把「模板」变成了真正能上手改的东西，并且把友链审核的回信补齐了。

## 模板可以随意改了

站内模板原先只能预览和复制，现在标题、HTML 正文、纯文本正文都能直接编辑，保存前有语法检查。

第一次保存会给模板打上 `halo.run/do-not-overwrite` 标记，Halo 之后升级不再用自带内容覆盖它；点「重置」会用 Halo 出厂的那份内容还原，并把这个标记摘掉，重新交回给 Halo 管理。

## 隐藏与删除

站内模板和自定义模板都支持隐藏。隐藏后不再出现在「写邮件」和「触发规则」的选择列表里，勾选「显示已隐藏」还能找回来。

自定义模板是硬删除。站内模板的删除同样可用，但它们由 Halo 自带，Halo 下次启动时会补齐缺失的那些，所以删除只对当前这次运行有效；想让某个模板长期不出现，用隐藏。

## 后台菜单单独成组

邮件中心的五个页面从「工具」分组里搬出来，归进侧边栏自己的「邮件中心」分组，不再和其他插件的功能混在一起。

## 模板切换按钮的背景

站内模板 / 自定义模板那两个切换按钮之前只有文字、看不出是可以点的，现在各自是独立的按钮，选中的那个用主题色填充。

## 友链审核自动回信

站点装了「链接管理」插件之后，友链申请审核通过和被拒绝都会自动给申请人回一封信。两封模板和两条规则会在检测到那个插件时自动创建，内容、收件人策略都能改，规则也能停用。

收件人取申请里填的邮箱；从评论识别出来的申请没有邮箱时，退回用那条评论的作者邮箱，两者都没有的这一条不会发。

审核结果来自对友链申请状态变化的监听而不是定时扫描，所以插件运行期间发生的通过 / 拒绝才会触发，启用之前已经处理完的申请不会被补发一遍。

四条默认内容只在「链接管理」在位、且它们都不存在时创建一次；删掉其中一条不会被补回来，四条全删后重启会重新创建。

## 升级说明

直接从插件页面上传 `plugin-mail-center-1.1.0.jar` 覆盖即可，发信配置、模板、触发规则和发送记录都会保留。已经在用「链接管理」的站点，升级后重启插件就能看到新增的两条友链规则。
