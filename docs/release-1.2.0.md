# 邮件中心 1.2.0

这一版修的是三个「明明配好了却没反应」的问题，其中一个让友链回信从 1.1.0 起就一直没生效。

## 友链审核回信

1.1.0 里审核通过和被拒绝都不会发信，而且日志里连一行痕迹都没有。原因是读取友链申请时用了插件自带的 JSON 转换器：它写不了 `Metadata` 里的时间戳，转换一抛异常，整条事件就被当成无关更新丢掉，看起来就像从没发生过。

改用 Halo 自己的转换器后恢复正常。顺手补上了「规则匹配到但没法发」时的记录：申请里没有邮箱、评论作者也不是邮箱身份、规则指向的模板被删掉，这几种情况现在都会在发送记录里留下一条「未发送」并写明原因，而不是静默跳过。

## 发送记录里能看到站点发的邮件

以前只有本插件自己发出的邮件会留档，Halo 本身和其他插件发出的通知在列表里完全看不到。现在会把这些站内通知一并收录，来源标为「站点通知」。

这一类记录有两个边界，需要提前说明：

- Halo 发信走的是内部邮件通知器，插件拿不到 SMTP 调用。能观察到的只有 Halo 为每次投递创建的站内通知，所以状态写作「站点已发出」，意思是站点已经处理过这条通知，不等于投递成功。
- 发给未注册访客的邮件（例如邮箱验证码）不会产生站内通知，因此收录不到。

## 模板默认留空

「写邮件」页面的模板来源和模板两个下拉原来默认停在「自定义模板」并自动选中第一个，很容易以为发的是一封、实际发的是另一封。现在两个都留空，必须先选来源再选模板，选完后可以随时改。

## 初始化自愈

友链模板和规则的创建从「有一个就不动」改成「缺什么补什么」，并用一个一次性标记记住已经初始化过：

- 上次启动中途失败留下的半套内容，升级后重启会补齐；
- 初始化完成之后再删掉其中任意一条，不会被重新加回来。

## 升级说明

上传 `plugin-mail-center-1.2.0.jar` 覆盖即可，发信配置、模板、规则和发送记录都会保留。已经在用「链接管理」的站点，升级后重启插件，两条友链规则会自动补齐；如果之前已经手动删过，它们不会回来。
